Consolidador de PDFs

Organize documentos em um arquivo único. Para PDFs assinados digitalmente, use Preservar originais: cada documento ficará anexado, intacto e verificável individualmente. Todo o processamento ocorre neste navegador.

Arraste para mudar a ordem, ou use as setas. “Possível assinatura” é apenas uma detecção estrutural: não representa validação criptográfica.

Tipo de consolidação

Selecione dois ou mais PDFs.
Privacidade: os documentos não são enviados pelo programa a serviços externos. As bibliotecas são baixadas da CDN, mas os arquivos são processados localmente. Em redes restritas, hospede as bibliotecas no próprio portal. Validação: extraia cada original e verifique a assinatura no Acrobat ou no VALIDAR/ITI (o uso de validadores externos envolve o envio do documento por iniciativa do usuário). Para acessar anexos no Acrobat: Menu → Exibir → Mostrar/Ocultar → Painéis laterais → Anexos. Nem todo visualizador exibe anexos.
